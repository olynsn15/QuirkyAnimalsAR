# QuirkyAnimalsAR

QuirkyAnimalsAR is an augmented reality application that showcases adorable 3D models of various animals with lively animations. Built using Unity, this app brings quirky creatures to life, providing a fun and interactive AR experience.

<br>

## Features

- Display 3D animal models in augmented reality.
- Smooth animations for each animal to enhance realism and engagement.
- User-friendly interface to browse and interact with different animals.

<br>

## Technologies Used

- **Unity** — Game engine used to develop the application.
- **AR Foundation** (optional, if used) — For building cross-platform AR experiences (ARKit & ARCore).
- **Assets**:
  - 3D animal models and animations from [Quirky Animals Series - Free](https://assetstore.unity.com/packages/3d/characters/animals/quirky-series-free-animals-pack-178235) by Unity Asset Store.
  - Additional assets sourced from Freepik.

<br>

## Getting Started

### Prerequisites

- Unity (version used for development)
- AR Foundation (if applicable)
- Compatible AR-capable device (iOS or Android)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/QuirkyAnimalsAR.git
2. Open the project in Unity.
3. Import the necessary packages including:
- Quirky Animals Series - Free asset pack
- Freepik assets (if any)
4. Build and run on your AR-enabled device.
